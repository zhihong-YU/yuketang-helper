统一 AI 配置使用说明（1.25.2）
日期：2026-10-20

安装
用本包中的 yuketang-helper.user.js 全部代码替换旧脚本，保存并刷新荷塘雨课堂。
原设置入口不变。打开设置，顶部现在是“AI 服务与模型”。
已有 Kimi 配置会保留，升级不会强制替换你填写的模型、地址和密钥。

新增 DeepSeek / GLM / Kimi
1. 在“新增模板”选择 DeepSeek、GLM · 智谱或 Kimi · 月之暗面。
2. 点击“按模板新增”。会创建独立配置，自动填写地址、模型与图文模式，API Key 留空。
3. 填入该平台的 API Key，也可以修改配置名称、模型 ID、地址、温度和请求超时。
4. 在设置底部“配置维护”点击“测试文字连接”，图文配置再点击“测试识图”。测试会发起实际模型请求并消耗额度。
5. 测试读取当前表单，不必先保存；通过后点击顶部“保存设置”才会应用到答题中心。

像配置切换器一样管理
• “当前配置”可以切换已添加的配置；切换时保留当前表单草稿。
• 新增、复制、删除和选择当前配置，均在点击“保存设置”后应用。
• “复制当前”保留同一服务的地址、模型和密钥，方便创建不同参数组合；副本可以单独编辑。
• “按模板新增”不会继承另一平台的密钥。
• 每份配置独立保存名称、API 地址、密钥、文本模型、图像模型、输入模式、温度和超时。
• 至少保留一份配置；可以保留尚未填写完的非当前配置草稿。
• 关闭并重新打开设置会重新读取已保存配置；未保存的修改会丢弃。

新增其他平台 / 自建代理
选择“自定义兼容服务”→“按模板新增”，填写名称、API 地址、API Key 和模型 ID。
自定义模板默认是纯文字模式；多模态模型可以改成图文模式并测试识图。
支持基础地址（例如 https://你的服务/v1、GLM /api/paas/v4）或完整 /chat/completions 地址。
当前调用方式：Bearer API Key、Chat Completions、非流式 JSON 响应。
原生 Anthropic Messages、Gemini 原生协议或 Responses 专用接口不能直接填进来；需使用服务商的 Chat Completions 兼容入口。
模型 ID 是自由输入框，没有限定只能使用预设模型。

图文和纯文字模式
图文：答题中心有本题图片时读图；没有图片时，只有可用的完整题干和选项才会走文字分析。
纯文字：答题中心不下载题目截图用于 AI，不发送 image_url；只发送题干和选项。
发现空题干、选择题缺选项、题干内含图片或明确引用图表时，纯文字模式会停止并提示切换图文配置。
即使没有命中上述检查，脚本也不能保证文字信息完整，仍需检查题目与 AI 建议。
“提问当前 PPT”是图片分析功能；当前配置为纯文字时会提示切换图文配置。

文本模型与图像模型
同一模型填在两处：直接看图解题。
同一平台中填写不同模型：先用图像模型提取题干、选项和图像事实，再由文本模型解题。
两步模型共用本配置的地址与密钥；目前没有跨平台识图后自动转交另一配置解题的路由。
图像模型留空表示使用文本模型来接收图片，不表示关闭图片输入；关闭图片应选择纯文字模式。

OCR 与翻译
原有独立 OCR / 翻译地址与密钥仍可配置，它们是全局覆盖项，不随当前配置切换为不同的覆盖值。
新增“OCR 模型 ID”，外接 OCR 服务时可指定识图模型，避免误用当前纯文本模型。
如果没有使用独立 OCR / 翻译服务，可将对应覆盖项留空。
课件 OCR 结果不会自动转交答题中心作为外接识图步骤。

连接测试、导入和导出
“测试文字连接”仅验证当前文本模型可返回内容。
“测试识图”发送内置的红色色块，检查返回是否识别红色，不发送课堂内容；通过也不代表复杂题目一定答对。
测试失败会显示请求错误或超时；默认每次模型请求超时为 120 秒，可设 15～300 秒。
导出保存过的全部设置和配置，不导出 API Key；导入后需核对密钥，自动答题、排队提交和自动进入默认关闭。
答题中心继续沿用“手填 / AI 预填 / 提交”的统一流程。修改正在使用的配置后，旧配置的迟到 AI 结果不会写入新任务。
