# 雨课堂助手

用于雨课堂／荷塘雨课堂的浏览器用户脚本，提供课堂提醒、课件浏览与 PDF 下载、统一答题中心，以及可自行添加的多 AI 服务配置。

**原作者与来源：**本项目基于 [ZaytsevZY](https://github.com/ZaytsevZY) 的 [yuketang-helper-auto](https://github.com/ZaytsevZY/yuketang-helper-auto) 改进，以用户提供的 **1.21.3 单文件脚本**为开发基线。基础实现及相应贡献归原作者和上游贡献者所有；本仓库由 [zhihong-YU](https://github.com/zhihong-YU) 维护后续改动。这里的版本号属于本仓库，不表示上游版本。详细来源见 [NOTICE.md](NOTICE.md)，上游许可证及附加说明原样保留在 [LICENSE](LICENSE)。

当前版本：**1.25.2**。主要使用方式为桌面浏览器配合 Tampermonkey；本仓库提供的是单文件用户脚本。

[安装脚本](https://raw.githubusercontent.com/zhihong-YU/yuketang-helper/main/yuketang-helper.user.js) · [更新记录](CHANGELOG.md) · [反馈问题](https://github.com/zhihong-YU/yuketang-helper/issues)

## 功能

| 功能 | 使用方式与范围 |
| --- | --- |
| 课堂提醒 | 新题、课件发布、课堂结束等事件提醒，支持页面弹窗、声音和系统通知 |
| 课件浏览 | 浏览当前网页已获取的课件和题目，可切换全部页面／题目页面 |
| 完整课件 PDF | 独立于浏览筛选导出完整课件；缺页或图片读取失败时提示失败，避免把缺页文件当作完整导出 |
| 按筛选导出 PDF | 只导出当前筛选出的页面 |
| 统一答题中心 | 自己填写和 AI 生成共用答案编辑区、预填草稿与提交队列 |
| 自己作答 | 选择题可点选；支持立即提交、保存后等待切页／开放、仅保存草稿 |
| AI 分析并预填 | 对已取得的题目进行分析，结果先进入编辑区，可检查和修改后提交 |
| 多 AI 配置 | DeepSeek、GLM、Kimi 模板及自定义兼容服务，支持新增、复制、删除和切换配置 |
| 图文／纯文字 | 每份配置可选择输入模式，并独立设置文本模型、图像模型、温度和超时 |
| 课件 AI 工具 | 提问当前 PPT、文字识别（OCR）和翻译 |
| 设置管理与诊断 | 设置导入／导出、文字连接测试、识图测试，以及最近的作答诊断记录 |

本仓库在基线脚本上重点改进了：配置与存储稳定性、完整 PDF 导出、提交兼容处理、人工与 AI 共用预填队列、多服务配置，以及底栏单一“答题中心”入口。继承自上游的功能不作为本仓库原创贡献。

## 安装

1. 在桌面浏览器中安装 [Tampermonkey](https://www.tampermonkey.net/)。浏览器如果提示需要允许用户脚本运行，请按扩展提示启用。
2. 打开 [安装脚本链接](https://raw.githubusercontent.com/zhihong-YU/yuketang-helper/main/yuketang-helper.user.js)，在 Tampermonkey 安装页确认安装。
3. 如果链接显示纯文本，可复制全部代码，在 Tampermonkey 中新建脚本、粘贴并保存。
4. 登录雨课堂／荷塘雨课堂，刷新网页后查看左下角工具栏。
5. 从其他版本迁移时，先停用旧脚本，避免多个副本同时操作页面。新安装的独立脚本不保证自动继承其他脚本的扩展存储，可使用设置导出／导入迁移。

工具栏包含：**提醒、课件浏览、答题中心、设置、教程**。自动 AI 预填开关位于答题中心内。

脚本匹配范围包括 `www.yuketang.cn`、`pro.yuketang.cn`、`changjiang.yuketang.cn` 的相应首页、课堂及部分移动页面，具体以脚本头部的 `@match` 为准。不同服务器的界面和权限可能不同；移动端主要保留提醒入口，完整交互以桌面课堂页为主。

## 配置 AI 服务

### 快速开始

1. 打开 **设置 → AI 服务与模型**。
2. 在“新增模板”选择 **DeepSeek / GLM · 智谱 / Kimi · 月之暗面**，点击“按模板新增”。
3. 填入该服务的 **API Key**，按账户权限确认模型 ID。
4. 在设置底部“配置维护”点击“测试文字连接”；图文配置再点击“测试识图”。
5. 点击顶部 **保存设置**，将当前配置应用到答题中心。

模板会填写地址和模型，密钥需要自行填写。模板值参考下列官方文档，核对日期为 **2026-10-20**，以后可自行修改。

| 模板 | 完整 API 地址 | 默认文本／图像模型 | 官方文档 |
| --- | --- | --- | --- |
| DeepSeek | `https://api.deepseek.com/chat/completions` | `deepseek-flash` | [视觉输入说明](https://api-docs.deepseek.com/guides/vision/) |
| GLM · 智谱 | `https://open.bigmodel.cn/api/paas/v4/chat/completions` | `glm-5.3-flash` | [模型说明](https://docs.bigmodel.cn/cn/guide/models/vlm/glm-5.3-flash) |
| Kimi · 月之暗面 | `https://api.moonshot.cn/v1/chat/completions` | `kimi-k3` | [模型列表](https://platform.kimi.com/docs/models) |

模板不代表账户一定已开通模型。GLM 模板使用标准模型 API，请使用对应产品的密钥。旧 Kimi 配置会保留；旧模型不可用时，可参考官方模型列表新增配置或修改模型 ID。

### 自己添加配置

选择 **自定义兼容服务 → 按模板新增**，填写以下项目：

| 字段 | 含义 |
| --- | --- |
| 名称 | 自己识别配置的名称，例如“GLM 看图”“我的代理” |
| API 地址 | 服务基础地址或完整的 `/chat/completions` 地址 |
| API Key | 当前服务的密钥 |
| 文本模型 ID | 服务商实际接受的模型名称，可自由填写 |
| 图像模型 ID | 图文模式下使用的模型；留空表示复用文本模型 |
| 题目输入 | 图文或纯文字，按模型实际能力选择 |
| Temperature | 留空不发送该参数，也可设置为 0～2 范围内的数值 |
| 请求超时 | 每次模型请求独立计时，可设 15～300 秒，默认 120 秒 |

基础地址如 `https://你的服务/v1`、GLM 的 `/api/paas/v4` 会自动补全聊天路径；完整接口地址会保留。推荐直接使用服务商文档给出的完整地址。

当前实现采用 **Bearer API Key + OpenAI 兼容 Chat Completions + 非流式 JSON 响应**。其他平台需要提供相应兼容入口；Anthropic Messages、Gemini 原生协议、Responses 专用接口不能直接代替这个接口。

“当前配置”用于切换，“复制当前”用于创建同一服务的参数副本。各配置独立保存模型、地址、密钥和参数；按模板新增不会继承另一平台的密钥。切换时会保留表单草稿，点击“保存设置”才会生效。关闭并重新打开设置会重新读取已保存值。

### 图文与纯文字的区别

- **图文模式：**有本题图片时发送图片分析；没有图片时，只有可用的题干和选项才会走文字分析。
- **纯文字模式：**只向模型发送题干和选项，不发送题目图片。题干为空、选择题缺选项、内容中带有图片或明确引用图表时会停止，并提示切换图文配置。
- **同一配置填两个不同模型：**先用图像模型提取题目，再由文本模型分析；两个模型共用该配置的地址和密钥。目前不支持跨配置、跨平台自动转交识图结果。

图像模型留空不会关闭图片输入。纯文本模型应明确选择“纯文字”。“提问当前 PPT”需要图片输入，因此应使用图文配置。

“测试识图”发送内置红色色块，检查返回是否识别颜色。它可以帮助发现接口不接受图片的情况，不能证明复杂题目一定能答对。

### OCR 与翻译

课件浏览提供 OCR 和翻译。可以复用当前 AI 配置，也可以填写独立的 OCR／翻译地址、密钥及模型。外接 OCR 时可使用“OCR 模型 ID”指定识图模型。

独立 OCR／翻译字段是全局覆盖项；它们不会随每份配置各自保存一组覆盖值。课件 OCR 结果目前不会自动转交答题中心作为外接识图步骤。

## 使用答题中心

### 自己写答案

1. 点击工具栏 **答题中心**，找到已获取的题目。
2. 选择题直接点选；填空或主观题在共用编辑区填写。
3. 根据需要选择“立即提交这份答案”“只保存草稿”或“保存并按所选时机提交”。

立即提交仍要求题目处于可作答状态。保存排队后可以取消，修改答案后需要重新保存或排队。

### 让 AI 分析并预填

配置并保存 AI 后，可以单独点击某题的 **AI 分析并预填**，也可以开启 **收到题目自动 AI 预填**。模型结果会先写入同一编辑区；你可以修改，再由共用队列按时机提交。

开启自动 AI 预填时，会同时开启队列自动提交。只想先查看建议，可以将默认提交时机设为 **仅预填，由我点击提交**，或者暂停自动提交。

### 三种提交时机

| 时机 | 条件 |
| --- | --- |
| 切到对应题目且开放后提交 | 原生网页切到这道题，且题目已经开放；默认选项 |
| 题目开放即提交，无需切页 | 本题已开放，不要求网页正在显示它 |
| 仅预填，由我点击提交 | 保存建议，等待人工点击提交 |

自动分析与自动提交可以分别暂停。手动改过的草稿和未保存输入优先，后台 AI 不会覆盖；你主动点击单题重新分析后，随后发生的新修改仍然优先。默认时机只用于之后新建的草稿，已保存的题目保留自己的时机。

同一题提交共用请求锁。提交失败或结果未知后不自动重发，需要检查后显式重新操作；切换课堂或配置后，旧任务的迟到结果不会写入新任务。队列草稿按课堂保存在本地，目前不包含在设置导出中。

## 下载完整课件

打开 **课件浏览**，选择课件并使用“完整课件 PDF”。它不受“只看题目页”的浏览筛选影响。需要只导出筛选结果时，使用对应的按筛选导出功能。

“完整”指网页已取得、当前账户可访问的该份课件全部页面。缺页、图片请求失败或服务端没有返回完整内容时会报错，不会绕过访问权限，也不会从尚未提供的数据中恢复原始 PPT 文件。

## 设置、数据与常见问题

- **导入／导出：**导出保存过的设置，不包含 API Key。导入后检查各服务的密钥，自动分析、队列提交和自动进入默认关闭。
- **本地存储：**优先使用脚本管理器的 GM 存储；不支持时使用站点本地存储作为兼容路径。配置不上传到本仓库。
- **模型调用：**题干、选项或课件图片会发送给你配置的模型服务，测试及分析可能产生 API 费用。
- **网页请求：**提交优先复用页面原生请求封装，必要时使用同源兼容请求和 CSRF 信息。
- **无工具栏：**确认网页匹配脚本运行范围、脚本管理器允许运行，并刷新页面。
- **连接失败：**核对完整 API 地址、模型 ID、密钥与产品类型；查看配置页显示的 HTTP 错误或超时原因。
- **AI 有结果却未提交：**检查提交时机、队列开关、原生网页是否切到对应题目，以及开放／关闭状态；在设置底部展开作答诊断。
- **纯文字模式提示信息不足：**题目可能只在截图中，或缺少选项／图形，改用支持图片的配置。

使用范围应遵守课程要求和所在平台规则。AI 建议需要自行判断，脚本不保证答案正确或提交一定成功。
